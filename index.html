Arquitectura Semántica de esta Página

Resumen rápido de cómo se combinan las etiquetas HTML5 con las utilidades de Tailwind CSS en este proyecto:

<header> + <nav>

Barra fija superior con sticky top-0, Flexbox horizontal en escritorio y menú desplegable en móvil.

<main> + <section>

Cuerpo único dividido en bloques temáticos usando grilla responsive lg:grid-cols-12.

<article>

Unidades autónomas reutilizables para cada tarjeta del catálogo con imagen uniforme (object-fit: cover).

<aside> + <footer>

Barra lateral complementaria (lg:col-span-4) y cierre institucional alineado al final con mt-auto.

Información Extra (<aside>)

Este panel usa <aside> porque aporta contexto complementario sin competir con el contenido principal.
