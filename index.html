Arquitectura Semántica de esta Página

Resumen rápido de cómo se combinan las etiquetas HTML5 con utilidades puras de Tailwind CSS sin usar ningún archivo .css:

<header> + <nav>

Barra fija superior con sticky top-0, Flexbox horizontal en escritorio y menú desplegable en móvil.

<main> + <section>

Cuerpo único dividido en bloques temáticos con scroll-mt-20 y grilla responsive lg:grid-cols-12.

<article>

Tarjetas reutilizables con imagen uniforme (h-52 w-full object-cover) y efecto elevación (hover:-translate-y-1).

<aside> + <footer>

Barra lateral complementaria (lg:col-span-4) y pie de página fijo al fondo con mt-auto.

Información Extra (<aside>)

Este panel usa <aside> porque aporta contexto complementario sin competir con el contenido principal.
